## PR review checklist for your teammate
Open `pnpm dev:web` (port 5174 by default) and check:

1. **Both themes** — toggle OS dark/light mode; every colour, border,
   and background should switch cleanly via tokens.css.
2. **Phone-width window** — drag the browser to ~360 px wide; verify
   no horizontal scroll, 16 px side gutters, all text readable.
3. **Network tab** — with the page loaded, open DevTools → Network and
   reload. Filter by "External" or check that no request goes to any
   domain other than localhost. Fonts load from /assets/ (bundled), not
   from fonts.googleapis.com or fonts.gstatic.com.
4. **Hero animation** — the privacy visual swaps between "What you see"
   and "What the server gets" every ~3 s. Reduce-motion: toggle
   "Emulate prefers-reduced-motion" in DevTools; the swap should still
   happen but without the fade-in animation.
5. **Keyboard navigation** — Tab through the page; focus ring should
   be visible on every interactive element (uses --focus from tokens).
6. **Headings order** — open the accessibility tree; h1 is "Skrim",
   h2 for each section, h3 for the footprint subsection only.
